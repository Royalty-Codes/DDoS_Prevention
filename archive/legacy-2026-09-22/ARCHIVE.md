# Legacy Implementation Archive

This directory preserves the pre-rebuild code, data, generated reports, and
notebook builders that were present before the measured SDN-lab rebuild on
2026-09-22.

It is retained for audit/reference only. Do not combine datasets or modules in
this archive with the new `sdn_ddos` capture pipeline: the old tree mixes a
63-column synthetic schema, a weak 28-column capture, and duplicated notebook
builders. The root DOCX files and `24059`, `24063`, `24076` notebooks were
intentionally left outside this archive as reference material.
